# SF系外惑星・宇宙文明名ジェネレーター

恒星系タイプ・惑星環境・文明レベルを設定してSF風の惑星名と文明の特徴を生成するアプリです。設定集のライブラリー保存とテキストエクスポートに対応しています。

## 機能
- 5恒星系タイプ × 7惑星環境 × 5文明レベルの組み合わせで惑星と文明を生成
- カタログ番号＋詩的惑星名（例: Kepler-442b「碧の孤星」）と文明名を自動生成
- 8つの特性（言語体系・政治体制・推定人口・技術水準・恒星環境・惑星環境・特記事項2件）を表示
- 文明設定の概要テキスト自動生成
- ランダムボタンですべてのパラメーターをランダム選択して即生成
- ハートボタンでライブラリーに保存（最大30件・localStorage）
- エクスポートボタンで全保存世界設定をテキスト出力・クリップボードコピー
